# 第六部分：完整部署操作手册

## 一、环境搭建全流程

### 1. Python 环境搭建

**Ubuntu / Debian:**
```bash
# 安装 Python 3.10+
sudo apt update
sudo apt install python3 python3-pip python3-venv -y

# 创建虚拟环境（推荐）
cd /home/ubuntu/code/代码/软件追踪/backend
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

**Windows:**
```powershell
# 下载 Python 3.10+
# https://www.python.org/downloads/
# 安装时勾选 "Add Python to PATH"

# 进入项目目录
cd "C:\Users\你的用户名\代码\软件追踪\backend"

# 创建虚拟环境
python -m venv venv
venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. Android Studio 配置

1. **下载安装：** https://developer.android.com/studio
2. **SDK 配置：**
   - 打开 Android Studio → Settings → Appearance & Behavior → System Settings → Android SDK
   - SDK Platform: 选择 Android 13 (API 33)
   - SDK Tools: 勾选 "Google Play services"
   - 点击 Apply 下载
3. **模拟器或真机：**
   - 模拟器：AVD Manager → Create Virtual Device → 选择 Pixel 6 → API 33
   - 真机：USB 调试开启 → 设置 → 开发者选项 → USB 调试

### 3. ngrok 下载安装

**Ubuntu:**
```bash
# 下载 ngrok
wget https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz
tar -xzf ngrok-v3-stable-linux-amd64.tgz
sudo mv ngrok /usr/local/bin/

# 认证（需要在 https://ngrok.com 注册免费账号）
ngrok config add-authtoken YOUR_AUTH_TOKEN

# 启动隧道
ngrok http 5000
```

**Windows:**
1. 下载：https://ngrok.com/download
2. 解压后运行：
   ```powershell
   ngrok.exe config add-authtoken YOUR_AUTH_TOKEN
   ngrok.exe http 5000
   ```

**macOS:**
```bash
brew install ngrok
ngrok config add-authtoken YOUR_AUTH_TOKEN
ngrok http 5000
```

## 二、服务端参数修改说明

编辑 `backend/server.py` 顶部的配置区域：

```python
# 第 19-28 行附近

# 修改鉴权 Token（必须与两个 APP 中的 Token 一致）
AUTH_TOKEN = "MySecureToken2024"

# 修改服务器监听端口
PORT = 5000

# 短信推送配置（可选）
SMS_PHONE_NUMBER = "13800138000"
SMS_ACCESS_KEY_ID = "your_access_key"
SMS_ACCESS_KEY_SECRET = "your_secret"
SMS_SIGN_NAME = "your_sign_name"
SMS_TEMPLATE_CODE = "your_template_code"
```

修改后重启服务：
```bash
cd backend
python server.py
```

## 三、安卓 APP 参数配置步骤

### 共享端 APP（sender-app）

打开 `sender-app/app/src/main/res/layout/activity_main.xml` 或直接在 APP 界面输入：

| 参数 | 说明 | 示例 |
|------|------|------|
| 服务器地址 | Flask 服务的外网或局域网地址 | `http://xxx.ngrok.io` 或 `http://192.168.1.100:5000` |
| 设备 ID | 本设备的唯一标识 | `device_abc12345` |
| 鉴权 Token | 与服务端一致的 Token | `MySecureToken2024` |
| 上传间隔 | 自动上传的时间间隔（秒） | `30` |

### 查看端 APP（viewer-app）

| 参数 | 说明 | 示例 |
|------|------|------|
| 服务器地址 | 同共享端 | `http://xxx.ngrok.io` |
| 鉴权 Token | 同共享端 | `MySecureToken2024` |
| 查询设备 ID | 要查看的设备 ID（留空查全部） | `device_abc12345` |
| 轮询间隔 | 自动刷新的时间间隔（秒） | `10` |

## 四、真机权限设置完整步骤

### 共享端 APP 需要的权限

| 权限 | 为什么需要 | 设置路径 |
|------|-----------|---------|
| 位置信息（精确） | 获取 GPS 坐标 | 设置 → 应用 → 位置共享 → 权限 → 位置 → 精确位置 |
| 通知 | 前台服务常驻通知 | 设置 → 应用 → 位置共享 → 通知 → 允许 |
| 后台运行 | 保持服务不中断 | 设置 → 电池 → 省电策略 → 无限制 |
| 开机启动 | 接收开机广播 | 设置 → 应用 → 自启动管理 → 允许 |

### 查看端 APP 需要的权限

| 权限 | 为什么需要 | 设置路径 |
|------|-----------|---------|
| 网络 | 访问服务器 | 设置 → 应用 → 位置查看 → 权限 → 允许 |
| 通知 | 新位置提醒 | 设置 → 应用 → 位置查看 → 通知 → 允许 |

### 各品牌手机特殊设置

**小米 (MIUI):**
```
设置 → 应用设置 → 应用管理 → 位置共享 →
  权限管理 → 位置信息 → 始终允许
  省电策略 → 无限制
  后台详情 → 允许后台运行
  自启动管理 → 开启
```

**华为 (HarmonyOS):**
```
设置 → 应用和服务 → 应用管理 → 位置共享 →
  权限 → 位置 → 始终允许
  启动管理 → 自动管理 / 手动管理（全部开启）
  耗电保护 → 关闭（允许后台活动）
```

**OPPO / Realme (ColorOS):**
```
设置 → 应用 → 应用管理 → 位置共享 →
  权限管理 → 位置信息 → 始终允许
  耗电管理 → 允许完全后台行为
```

## 五、标准化测试流程

### 第一步：启动 Flask 服务
```bash
cd backend
source venv/bin/activate  # 如果使用虚拟环境
python server.py
```
看到以下输出表示成功：
```
============================================================
  自愿共享位置系统 - 中转服务器
============================================================
  监听地址: http://0.0.0.0:5000
  ...
============================================================
 * Running on http://0.0.0.0:5000
```

### 第二步：暴露到公网（可选）
```bash
# 另一个终端窗口
ngrok http 5000
```
记下 ngrok 给出的地址，如 `https://abc123.ngrok.io`

### 第三步：测试服务器健康状态
```bash
curl http://127.0.0.1:5000/health
# 应返回: {"status":"ok","uptime_seconds":...}
```

### 第四步：安装共享端 APP
1. Android Studio 中打开 `sender-app` 项目
2. 点击 Run (▶) 按钮，选择真机或模拟器
3. APP 安装完成后打开
4. 填入服务器地址、设备 ID、Token
5. 授予定位权限
6. 点击"手动上传一次定位"
7. 观察日志显示"上传成功"

### 第五步：安装查看端 APP
1. Android Studio 中打开 `viewer-app` 项目
2. 点击 Run (▶) 按钮安装
3. APP 安装完成后打开
4. 填入相同的服务器地址和 Token
5. 在"查询设备 ID"中输入共享端的设备 ID
6. 点击"立即刷新"
7. 应该能看到共享端的位置卡片

### 第六步：测试自动轮询
1. 在查看端点击"开始自动刷新"
2. 等待设定的轮询间隔
3. 在共享端再次手动上传定位
4. 查看端应该自动获取到新位置并弹出通知

3. **朋友间互助**：朋友之间**主动开启、随时可关**的位置共享

### 合规设计保证

本项目在设计上保证了透明性：

1. **共享端 APP 首页永久显示"位置共享中"状态**，用户随时可见
2. **通知栏常驻通知**，用户滑下通知栏即可看到
3. **所有功能需用户手动触发**，无自动后台采集
4. **无隐藏图标、无系统托盘静默运行**
5. **开机不会自动开启定位**，只会弹出一条提醒通知
6. **不提供任何形式的隐蔽监控功能**
