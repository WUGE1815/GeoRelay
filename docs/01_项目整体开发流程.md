# 第一部分：项目整体开发流程文档

## 1. 技术栈说明

| 组件 | 技术选型 | 版本要求 | 用途 |
|------|---------|---------|------|
| 后端服务 | Python 3.10 + Flask | Python ≥ 3.10 | 中转服务器，接收和转发定位数据 |
| 共享端 APP | Kotlin + Android | API 26+ (Android 8.0+) | 主动共享自身位置的客户端 |
| 查看端 APP | Kotlin + Android | API 26+ (Android 8.0+) | 查看他人共享位置的客户端 |
| HTTP 客户端 | OkHttp 4.x | 4.12.0 | Android 端网络请求 |
| 定位服务 | Google Play Services Location | 21.0.1 | GPS + 网络融合定位 |
| 内网穿透 | ngrok | 最新版 | 将本地 Flask 服务暴露到公网 |
| 跨域支持 | flask-cors | 最新版 | 允许 Android APP 跨域请求 |

## 2. 完整数据流

```
┌─────────────────┐         HTTP POST         ┌──────────────────┐
│  共享端 APP     │ ─────────────────────────→ │                  │
│  (Sender)       │  /upload_loc + Token       │  Flask 服务器    │
│                 │                            │  (中转中心)      │
│ 用户手动点击    │                            │                  │
│ "开始共享"      │                            │  ├─ 存入 txt     │
│ 首页明确显示    │                            │  ├─ 内存缓存     │
│ "位置共享中"    │                            │  └─ 转发给查看端 │
└─────────────────┘                            └────────┬─────────┘
                                                         │
                                              HTTP GET   │ /poll?token=xxx
                                                         │
                                                         ▼
┌─────────────────┐         ← ← ← ← ← ← ← ← ←─────── ┌──────────────────┐
│  查看端 APP     │                                  │  数据存储        │
│  (Viewer)       │                                  │  data/           │
│                 │                                  │  location_history│
│ 手动/自动刷新   │                                  │  .txt            │
│ 查看位置卡片    │                                  └──────────────────┘
│ 一键跳转地图    │
└─────────────────┘
```

## 3. 分阶段开发流程

### Phase 1: 环境搭建
1. 安装 Python 3.10+，创建虚拟环境
2. 安装 Flask 及相关依赖
3. 安装 Android Studio，配置 SDK 和模拟器/真机
4. 安装 ngrok（如需外网访问）

### Phase 2: 后端服务开发
1. 编写 Flask 服务器 `server.py`
2. 实现 `/upload_loc`、`/poll`、`/get_history` 等接口
3. 实现 Token 鉴权和频率限制
4. 本地测试所有接口

### Phase 3: 共享端 APP 开发
1. 创建 Android 项目，配置依赖
2. 实现主界面（状态显示、控制按钮、配置输入）
3. 实现前台定位服务
4. 实现 OkHttp 上传逻辑
5. 真机测试定位采集和上传

### Phase 4: 查看端 APP 开发
1. 创建 Android 项目
2. 实现位置列表展示
3. 实现轮询和通知功能
4. 一键跳转地图
5. 与共享端联调

### Phase 5: 外网部署
1. 使用 ngrok 暴露 Flask 服务
2. 在两个 APP 中配置公网地址
3. 跨设备测试

### Phase 6: 真机联调与优化
1. 多设备测试
2. 权限问题排查
3. 网络异常处理
4. 用户体验优化

### 安装步骤

#### Python 环境
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv -y

# 创建虚拟环境
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

#### ngrok
```bash
# 下载并解压
wget https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz
tar -xzf ngrok-v3-stable-linux-amd64.tgz
chmod +x ngrok

# 认证（注册 ngrok.com 免费账号获取 token）
./ngrok config add-authtoken YOUR_TOKEN

# 启动隧道（暴露 5000 端口）
./ngrok http 5000
```

## 5. 合规设计说明

本项目严格遵守以下合规原则：

1. **用户知情同意**：共享端 APP 首页永久显示"位置共享中"状态指示，通知栏常驻通知，用户随时可见
2. **手动触发**：所有定位采集和上传均需用户手动点击按钮触发，无自动后台采集
3. **无隐藏功能**：无隐藏图标、无系统托盘驻留、无绕过电池优化的逻辑
4. **随时可停**：用户随时可以点击"停止共享"按钮终止服务
5. **开机不自动启动**：开机广播仅弹出一条提醒通知，不会自动开启定位服务
6. **透明权限申请**：所有权限申请均有明确的弹窗说明，告知用户用途
7. **自愿共享**：两个 APP 配合使用，一方主动共享，另一方主动查看，双方均知情
